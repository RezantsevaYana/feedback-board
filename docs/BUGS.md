## Этап 2 (29.10.2026)

Найдено при ручном прогоне фичи «закрытые доски» в браузере.

- [x] **Залогиненному в SubmitForm на доске показывается пустое поле «Ваше имя» → без ввода пост создаётся как аноним.**
  Шаги: войти под `admin@example.com`, открыть `/demo`, нажать «Предложить». В модалке «Новое предложение» поле «Ваше имя» пустое, hint «по желанию»; если ничего не ввести — `author_name` в запрос не кладётся, бэк пишет аноним.
  Ждём: имя из аккаунта подставлено автоматически, поле видно, но правка невозможна (чтобы не плодить псевдонимов на закрытой доске).
  Где: `frontend/src/shared/components/SubmitForm.vue` (поле «Ваше имя» рисуется безусловно, начальное значение из `localStorage['fb-author-name']`); `pages/board/components/SubmitModal.vue` и `pages/board/BoardPage.vue` не прокидывали в форму ничего об авторизации.
  Починено частично 29.10.2026: добавлен проп `author?: { name: string } | null`; если задан — поле prefilled и `disabled`, hint «из вашего аккаунта»; `SubmitModal` пробрасывает проп, `BoardPage` передаёт `{ name: board.me.name }`. Виджет-гость не затронут. Полное закрытие — вместе с планом «посты автор по аккаунту» (нужны `posts.author_user_id` + серверная связь), см. ниже.

- [x] **У Post нет `user_id` — автор идентифицируется только по cookie `author_token`, в закрытых досках даёт дубли.**
  Шаги: на закрытой доске один человек заходит с лаптопа и телефона — у него две разные куки `voter_token`, в лидерборде будет посчитан как два разных автора под одинаковым именем.
  Ждём: пост/голос залогиненного юзера привязан к `user_id`, один аккаунт = один голос с любого устройства.
  Где: БД (`posts`, `votes`), `backend/app/Http/Controllers/Api/Public/PostController.php@store`, `VoteController@store/@destroy`.
  Починено 29.10.2026: добавлены `posts.author_user_id` и `votes.user_id` (nullable, FK users ON DELETE SET NULL) + partial unique `(post_id, user_id) WHERE user_id IS NOT NULL`; `voter_token` стал nullable (fallback для анонимов). PostController при залогиненном игнорирует присланное `author_name`, пишет `$user->name`. VoteController ищет голос сперва по `user_id`, cookie — только для анонимов. 7 feature-тестов в `AuthorAccountTest`. Лидерборд пока по старому — переделается, когда будет метрика «активные участники закрытых досок».
  Лидерборд переделан 30.10.2026: на деле было хуже, чем дубли — посты из аккаунта не создают запись в `voters`, и `join` по токену выкидывал залогиненных авторов из рейтинга совсем. Теперь автор — аккаунт (`posts.author_user_id`, имя из профиля), а для гостя — браузер (`author_token` + `voters.display_name`). Токен браузера больше не уходит наружу (по нему голосуют): строка несёт непрозрачный `key` и флаг `me` («это вы» по аккаунту или по токену). 6 тестов в `LeaderboardTest`.
