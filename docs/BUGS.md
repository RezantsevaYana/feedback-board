Найдено при ручном прогоне флоу этапа 1 в браузере (28.10.2026). Порядок — по важности.

- [ ] **Залогиненный голосующий / читатель видит на доске «Вход для команды».**
  Шаги: войти под голосующим → открыть доску (`/flow-test`). В сайдбаре кнопка «Вход для команды», по клику — форма почта + пароль, хотя человек уже вошёл.
  Ждём: вместо кнопки — «Вы вошли · роль Голосующий · ← Мои доски · Выйти».
  Где: `frontend/src/pages/board/BoardPage.vue` (`v-else` у `.team-login`, ~стр. 112), `useBoardStore` уже знает `me` и `role`.
  Там же: в `LoginModal.vue` устаревший текст «Аккаунты заводит разработчик, у каждого свой пароль» — аккаунты теперь появляются по приглашению или регистрации.

- [ ] **`/app` показывает «Доска не найдена».**
  Шаги: открыть `http://localhost:5176/app`. Роут `/:slug` ловит `app` как slug доски.
  Ждём: редирект на `/app/boards`.
  Где: `frontend/src/router/` — добавить `{ path: '/app', redirect: '/app/boards' }` выше `/:slug`.

- [ ] **Сидер: на Demo нет владельца.**
  `admin@example.com` прикреплён к доске как Админ, `projects.owner_id` пустой. В участниках у него «Админ · добавлен вручную», «Удалить доску» на Demo не видит никто.
  Ждём: сидовый админ — Владелец (`owner_id` + роль `owner` в pivot), в участниках «создал доску».
  Где: `backend/database/seeders/DatabaseSeeder.php` (~стр. 36–40).

- [ ] **Невалидная почта в приглашении молча выкидывается.**
  Шаги: «+ Пригласить» → ввести `anna@acme.com, bad-email, boris@acme.com`. Кнопка «Отправить 2 письма», про `bad-email` ни слова.
  Ждём: подсказка под полем «Не распознано: bad-email» (письма по остальным всё равно можно отправить).
  Где: `frontend/src/pages/app/components/InviteModal.vue`, `parseEmails`.
