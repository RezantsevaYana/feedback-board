# Роли — где смотреть флоу

Этот файл был первой итерацией прототипа в текстовом виде (ASCII-мокапы). После того, как прототип переехал в HTML, здесь остаётся только указатель:

- **Визуальный прототип** — `frontend/demo/roles-prototype.html`
  Открывается на `http://localhost:5175/roles-prototype.html` при поднятом `docker compose up`.
  Содержит блок-схему всех флоу, таблицу ролей, десять ключевых экранов (письма, принятие приглашения, запрос доступа, апрув, кабинет, список участников), раздел «Решения» и «Следующие шаги».
- **Продуктовый план** — `docs/ROLES_PLAN.md`
  Актуальный список решений, этапов реализации и чеклистов. Источник правды для разработки.

Если нужна текстовая версия отдельных сценариев для вставки в тикет / PR-описание — скопируй соответствующие caption-блоки из HTML.
