# Хэндофф для следующей сессии

Открытая задача: **админка сервиса на Orchid Platform** (как в `../kerrdental.ru`). План и чеклист — `docs/PLATFORM_ADMIN_PLAN.md`; продолжать с первого неотмеченного пункта.

## Где что

- Ветка `adminka`. Ничего не закоммичено — пользователь коммитит сам.
- В рабочей копии лежит первая Vue-версия админки (`/app/platform`, флаг `is_superadmin`) — по плану её первым делом откатываем (этап 0), миграция `is_superadmin` применена в локальной базе.
- Образец — `../kerrdental.ru`: `app/Orchid/`, `app/Enums/OrchidRoutes.php`, `routes/platform.php`, `config/platform.php`. Только читать, kerr тестируем только на localhost:1032.
- Прошлая задача (правки по ручной проверке ролей) — `docs/ROLES_FEEDBACK_PLAN.md`, баги — `docs/BUGS.md`.
- Письма: Mailpit http://localhost:8025.

## Правила (из памяти и проекта)

- Ответы пользователю — на русском.
- Не коммитить.
- Фронтенд — по `frontend/CLAUDE.md` (SCSS без BEM, компоненты из `shared/ui`, API через `api/*`).
