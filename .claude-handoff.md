# Хэндофф для следующей сессии

Открытая задача: **прогнать `/impeccable critique` (или `audit` / `polish`) по решению «цвет категорий и статусов»** — я только что его реализовала.

## Что сделано

Ветка `testbranch`. Админ может выбирать цвет из палитры 6 оттенков (`red, orange, yellow, green, blue, pink`) для:
- **категорий** (CategoryTag на карточках) — pastel-фон
- **статусов** (Status pill в колонках канбана, карточках, топ-листе) — saturated text + 12% tint

Палитра одна (`PALETTE_COLORS` в `frontend/src/api/types.ts`), но два набора CSS-переменных:
- `--cat-{slug}` — pastel-фоны для тегов категорий
- `--sta-{slug}` — насыщенные цвета для pill-ов статусов (text + color-mix 12% tint)

Оба набора — для светлой и тёмной темы в `frontend/src/scss/base/_tokens.scss`.

Picker — компонент `frontend/src/pages/board/components/ColorPalette.vue`: ряд круглых swatch-ей, стилизован pastel-цветами (как категорийный tag). Для статусов swatch тоже pastel — есть риск визуального расхождения: swatch pastel, pill saturated. Это точка под критику.

Разметка:
- Категория: `<span class="type slant" :data-color="category.color ?? 'none'">`
- Статус: `<span class="pill" :data-color="status.color ?? 'none'">` (во всех 5 местах рендера)
- Fallback `'none'` → нейтральный `--tag` / `--s-new`

## Контекст проекта (для impeccable)

- Design manifesto в `scss/base/_tokens.scss` сверху: «Green is the one hue… Purple is left out of the board: next to green it read as acid.» Я подобрала pastel/sta-палитру с заметным сдвигом в сторону muted/sage, но стоит проверить, не разъехалось ли с общей палитрой.
- Светлая тема первична, тёмная тоже существует (`[data-theme='dark']` + `prefers-color-scheme`).
- Пример смешения: до правок все pill-ы были серыми (--s-new) для кастомных статусов — слабая дифференциация. Теперь admin явно выбирает.
